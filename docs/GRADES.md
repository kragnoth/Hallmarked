# Grades of Work & Affixes

Hallmarked gives equipment **two independent layers**:

1. **Quality.** One stamped mark with fixed values, such as *Rusted* or *Legendary*. This is the original system.
   Equipment rolls it the first time it's seen, and the Assay Anvil can re-roll it.
2. **Grade of work.** How well the piece was made. The grade decides how many **affixes** roll and how strong
   they are. It is set once, when the item is created or looted, and **can't be re-rolled at the Assay Anvil**,
   so finding or crafting a good piece stays meaningful.

The two stack freely. A *Rusted*, Masterwork "Grim Ledger" sword is possible.

## Grades

| Grade | Colour | Affixes | Roll range | Crafted odds | Loot odds | Name |
|---|---|---|---|---|---|---|
| Shoddy | dark grey | 1 flaw | 0–100 % | 14 % | 6 % | *Warped Iron Sword* |
| Common | white | — | — | 55.5 % | 36 % | vanilla name |
| Journeyman | blue | 1–2 (≤1 prefix, ≤1 suffix) | 0–60 % | 23 % | 36 % | *Honed Iron Sword of Haste* |
| Masterwork | yellow | 3–4 (≤2/≤2) | 25–85 % | 7 % | 19 % | titled, e.g. *Ashen Vow* |
| Gearwrought | gold | 5–6 (≤3/≤3) | 60–100 % | **0.5 %** | 3 % | titled |

* The **roll range** is where each affix lands within its own min–max. Gearwrought affixes always land in the
  top 40 % of their range.
* **Crafted odds** apply to anything not generated by a loot table: crafted, traded, given, or dropped from a mob's
  held gear. Crafted gear can still come out Gearwrought.
* **Loot odds** apply to chests, mob loot tables, fishing and archaeology. The grade is rolled when the loot generates.
* **Custom sources:** a pack can add its own grade loot modifiers that name a source, such as `"boss"` or `"deep"`, and
  give grades a matching weight. Sources a grade doesn't list fall back to `loot`, then `crafted`. See below.
* **Luck** multiplies each grade's weight by `1 + luck × LuckFactor × luck_scaling`. LuckFactor defaults to 0.15.
  The scaling is −1 for Shoddy, 0 for Common, then 1, 2 and 3 for the higher grades, so Luck mostly pushes odds
  toward the top end.
* Titled items show the base item on the tooltip line under the title.

An item can't roll two affixes from the same `group` (for example, Honed and Weighted share `melee_damage`).
Turn on advanced tooltips (F3+H) to see each affix's name and min–max range next to its rolled value.

## Fusions (24)

Rolling is unchanged. After an item rolls, any two of its affixes that match a defined **fusion** are shown as one
named compound with the same stats and values.

* Each affix joins at most one fusion. Affixes that don't pair up stay as they are.
* On a **Journeyman** piece, the fusion takes the prefix or suffix spot in the name: Honed + of Haste becomes
  *Duelist's Iron Sword*.
* On **titled** grades, the fusion's title noun replaces the second word of the title: *Ashen Vow* becomes
  *Ashen Riposte*.
* In the tooltip, each fused pair gets a named line with both of its stats grouped beneath it.

## Data format

`data/<ns>/grades/<id>.json`
```json
{ "name": "hallmarked.grade.masterwork", "color": "yellow", "rank": 3,
  "affixes": { "min": 3, "max": 4 }, "max_prefixes": 2, "max_suffixes": 2, "flaws": 0,
  "roll": { "min": 0.25, "max": 0.85 }, "titled": true, "hidden": false,
  "luck_scaling": 2.0, "weights": { "crafted": 7, "loot": 19 } }
```

`data/<ns>/affixes/<id>.json`
```json
{ "name": "hallmarked.affix.honed", "type": "prefix", "weight": 10, "group": "melee_damage",
  "tool": { "modifiers": [ { "name": "honed_attack_damage", "attribute": "minecraft:generic.attack_damage",
                             "operation": "multiply_total", "min": 0.03, "max": 0.12 } ] } }
```
* `type` is `prefix`, `suffix` or `flaw`.
* Sections are the same as for qualities: `tool`, `bow`, `shield`, `armor`, `helmet`, `chestplate`,
  `leggings`, `boots`, `bauble`.
* Items store a 0–1 roll per affix rather than a final number, so rebalancing an affix's range in data updates
  existing items.

`data/<ns>/fusions/<id>.json`
```json
{ "name": "hallmarked.fusion.duelists", "type": "prefix",
  "parts": [ "hallmarked.affix.honed", "hallmarked.affix.of_haste" ],
  "title": "hallmarked.fusion.duelists.title", "priority": 0 }
```
* `type` sets where the fused name goes in a Journeyman name.
* `title` is optional.
* When two fusions want the same affix, the one with the higher `priority` claims it first.
* Fusions are worked out when the item is displayed, not stored on it, so adding or changing them updates existing items.

`data/<ns>/titles/*.json` — word lists for titled grades
```json
{ "replace": false, "first": ["Ashen", "Bitter", "..."], "second": ["Vow", "Toll", "..."] }
```
* Lists from every file merge together. `"replace": true` discards everything loaded before it.
* Items store the words they rolled, so editing the lists never renames gear players already have.

`data/<ns>/loot_modifiers/*.json` — extra grade sources
```json
{ "type": "hallmarked:grade_loot", "source": "boss",
  "conditions": [ { "condition": "neoforge:loot_table_id", "loot_table_id": "minecraft:entities/wither" } ] }
```
* Register the file in `data/neoforge/loot_modifiers/global_loot_modifiers.json`, **before** `hallmarked:grade_loot`.
* The first modifier to grade an item wins.
* Then give each grade a `"boss"` weight.

## Overriding and disabling
* **Override:** any namespace can replace an entry by reusing its `name`, or by replacing the file at the same path.
* **Disable:** `{ "name": "hallmarked.fusion.duelists", "enabled": false }` switches off an entry, including built-in
  ones. This works for qualities, grades, affixes and fusions.
* **Remove from rolls but keep on existing items:** set its `weight` to 0.

## Which items count as equipment
Item tags decide, with class checks as a fallback for items that aren't tagged:

| Tag | Default contents |
|---|---|
| `hallmarked:equipment/tool` | `#minecraft:swords`, `axes`, `pickaxes`, `shovels`, `hoes`, `#c:tools/melee_weapon`, `#c:tools/mining_tool`, `#c:tools/mace`, `#c:tools/spear` |
| `hallmarked:equipment/bow` | `#c:tools/bow`, `#c:tools/crossbow` |
| `hallmarked:equipment/shield` | `#c:tools/shield` |
| `hallmarked:equipment/helmet` … `/boots` | `#minecraft:head_armor` … `#minecraft:foot_armor` |
| `hallmarked:equipment/excluded` | empty. Anything here never gets a quality or grade. |

Order of checks:
1. The `excluded` tag.
2. Curios tags (bauble).
3. The equipment tags above.
4. Fallback by class: `TieredItem`, `BowItem`/`CrossbowItem`, `ShieldItem`, `ArmorItem`, and Tetra modular items.

The fallback covers mods that ship an untagged sword or bow.

## `/hallmarked defaults rebuild <world|kubejs>`
Writes all of Hallmarked's built-in data out as editable files. Requires op level 2.
* `world` writes to `<world>/datapacks/hallmarked_defaults/` and adds a `pack.mcmeta`.
* `kubejs` writes to `kubejs/data/hallmarked/`.
* Folders written: `qualities`, `grades`, `affixes`, `fusions`, `titles`, `loot_modifiers` and `tags/item/equipment`.
* Whatever is already in those folders is first copied to `hallmarked_backups/<timestamp>-<target>/` in the game
  directory, then replaced. Other namespaces aren't touched.
* Run `/reload` afterwards.

Unique and Set items are planned for a later version.
